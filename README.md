# Solar Challenge - Week 1  
**Data Discovery & Analysis for 10 Academy Solar Challenge**  

This repository contains the initial setup and exploratory analysis for the 10 Academy Solar Data Discovery challenge.

## 🛠️ Setup  

### Prerequisites  
- Python 3.x  
- Git  

### Installation  

1. **Clone the repository**  
   ```bash
   git clone https://github.com/Simbo-Fekadu/solar-challenge-week1.git
   cd solar-challenge-week1
   ```

2. **Set up a virtual environment**  
   ```bash
   python -m venv venv
   # Activate the environment:
   # Linux/Mac:
   source venv/bin/activate
   # Windows:
   .\venv\Scripts\activate
   ```

3. **Install dependencies**  
   ```bash
   pip install -r requirements.txt
   ```

4. **Verify setup**  
   ```bash
   python --version
   ```
